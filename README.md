# Myles Call Pickleball

Your coaching website. Live at **https://mylescall.com**.

## Change words or prices
Open **`content.ts`**. Everything on the site is in there. Anything marked `PLACEHOLDER` is a guess — swap in the real thing.

Easiest way: ask Claude, e.g. *"Change the private lesson price to $70."*

## Publish
Push to the `main` branch. The site updates by itself in about a minute.

## Preview on your computer
```
npm install
npm run dev
```
Then open http://localhost:3000.

## Rules
- This code is **public**. No passwords, keys, home address, or personal phone number in here.
- Don't sign up for anything paid — ask Dad first.
